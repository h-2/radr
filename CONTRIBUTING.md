# Contributing

Thanks for wanting to contribute! Before starting to work on something, it might be best to reply to the issue that you want to work on (or open a new one!).


## Be excellent to each other

We want this project to be a place where everyone's excellent to each other. Should the project grow in size, it might adopt a CoC at some point.


## AI Policy

This repository adheres to the [LLVM AI Tools Policy](https://llvm.org/docs/AIToolPolicy.html).

As of summer-of-2026, almost all code in this repository has been written by organic, grass-fed humans :cow: Since we like programming, this will likely remain the default for core library code.

For future contributions, the following shall be observed:
* The **documentation** in the docs folder is required to be written by humans without exception. 
* For **library code** and inline code documentation, follow the *as-if* rule, i.e. the person submitting code must have written the code themselves or be able to act in every way *as-if* they had written the code themselves. This includes being able to explain every line and being legally allowed to submit the code under the library [licensing terms](./LICENSE.md).
* For **testing code** (unit tests, benchmarks) the rules are slightly more lenient (but obviously you should be able to explain test code, too).

We highly recommend that contributions to the core library be written by humans, especially when contributing to the project for the first time.
